## umax/LT 1.5

Honestly, i wouldn't recommend using it sure, it's written in Rust, but there are more modern code editors available you'd be better off using those.

## Story

For a long time, I was looking for the right code editor there are so many of them out there and I eventually stumbled upon Torvalds repository (uemacs). I started using it and... I liked it oddly enough. I hate unnecessary clutter in editors situations where you're forced to type a billion commands just to exit - it's infuriating. However, as many of you probably know, uemacs is written in C a language many would agree is unsafe so I wondered: what if I wrote my own version? And that is the reason you are reading this text. Yes, it’s too small not professional-grade, and not a major tool like Vim, Emacs, or VS Code.

Why umax?
The reason for this is probably that, for a long time, the sound of uemacs struck me as odd (no offense intended!), and I wondered: what if I removed the e? that leaves umacs, so I decided to replace the cs with something else I chose x resulting in umax. Yes, it really is that simple there’s no magic to it.
